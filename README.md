# Metrics Insight

Metrics Insight is a data analytics and monitoring project developed
as part of the Zalvantic Data Science Internship.

## Week 1: Metrics Simulator and API Skeleton

### Project Features
- Generates simulated application metrics.
- Includes CPU usage, response time, and error rate.
- Contains labelled incidents such as spikes, level shifts, drift, and gaps.
- Stores metric records in an SQLite database.
- Provides a FastAPI application for metric monitoring.

### Project Files
- main.py: FastAPI application and API endpoints.
- models.py: Database model.
- database.py: Database connection.
- metrics_insight_week1.csv: Generated metrics dataset.
- week1_metrics_insight.ipynb: Data simulation and analysis notebook.
